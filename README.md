# 8:45 AM: The Demo Rush — Choose-Your-Path Story Engine

An interactive, browser-based branching story game built with HTML5, CSS3, and JavaScript.

## Live Demo
https://willowy-beignet-414f5e.netlify.app

## Features
- **JavaScript State Machine:** Dynamic story nodes with branching paths and 4 unique endings.
- **Time & Stress HUD:** Choices dynamically update the live clock and stress meter.
- **Inventory System:** Collecting items (College ID, Laptop & Charger) unlocks conditional paths.
- **Auto-Save:** Uses browser `localStorage` to save and resume progress without a backend.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
